# 验证数据使用说明

这份文档教你**怎么用这套数据检验系统算得对不对**。不需要懂代码，
照着做就行。

---

## 一、这套数据是干什么的

系统里最核心的功能是"算出一个分数 F，再根据 F 判定适宜性等级"。
这套数据就是用来检验**这个计算过程有没有算错**的。

做法是：每个算例先**手工推算**出应该得多少分，写成"期望值"；
再让系统自己算一遍，两边对不上就说明有问题。

> 关键点：期望值是**先用手算出来的**，不是拿系统的输出当标准。
> 否则就是"用系统验证系统"，等于没验。

一共 **8 个算例**，覆盖计算里最容易出错的地方：

| 算例 | 检验什么 |
|---|---|
| 01 理想上限 | 所有指标都取最优，应该得满分 1.0000 |
| 02 理论下限 | 所有指标都取最差，应该得 0.0000 |
| 03 面积加权 | 三个单元按面积占比加权，加权公式对不对 |
| 04 污染取限值 | 8 种重金属全部超标，污染指标算得对不对 |
| 05 岩质边坡忽略土壤 | 岩质边坡不该算土壤指标，多填了也不能算进去 |
| 06 平台忽略地形 | 平台不该算地形指标，多填了也不能算进去 |
| 07 坡度分界 | 25° 分界、坡向赋值算得对不对 |
| 08 一票否决 | 限制性条件不通过时，必须拒绝评价 |

另外还会单独核对**等级分界线**：F 正好等于 0.3 或 0.7 时，该判哪一档。

## 三、方式一：一条命令自动核对（推荐）

打开项目文件夹，在地址栏输入 `cmd` 回车，会弹出一个黑色窗口。然后输入：

```bat
python 工具\数值核对\验证用例.py
```

回车后会看到每个算例的推算过程和比对结果。**全对的话最后会显示：**

```
==============================================================================
  全部算例与期望值一致，系统计算正确 ✓
==============================================================================
```

### 输出怎么看

每个算例分三段：

```
------------------------------------------------------------------------------
算例 03  面积加权：三类单元混合，验证式(9) 的加权合成
------------------------------------------------------------------------------
    推算｜面积占比：岩质 2/10=20%，碎石 5/10=50%，平台 3/10=30%
    推算｜岩质边坡：…… F' = 0.45×0 + 0.55×0.712 = 0.3916
    ...
    期望｜F = 0.4366，等级 = 基本适宜
    实际｜F = 0.4366，等级 = 基本适宜
    判定｜[一致] ✓
    单元｜岩质边坡   期望 F′ = 0.3916   实际 F′ = 0.3916   [一致] ✓
```

- `推算｜` 是手算过程（照着论文公式一步步算的）
- `期望｜` 是手算得到的结果
- `实际｜` 是系统算出来的结果
- `判定｜` 两边一致就是 ✓

### 为什么要逐个核对"单元得分"

只对总分是不够的 —— 三个单元一个算高了、一个算低了，加权之后可能
正好互相抵消，总分看着对，其实每个单元都错了。所以脚本会**连每个
单元的得分 F′ 也单独核对**。

### 附带做的两件事

1. **等级边界核对**：F = 0.2999 / 0.3000 / 0.6999 / 0.7000 四处，
   看系统判的档位对不对。
2. **孪生对照**（算例 05、06 专属）：同一个图斑，另外建一份
   **不填那些多余指标**的数据，要求两者的 F **完全相同**。
   这就证明"不该算的指标确实没被算进去"。

### 跑完之后

算例会**保留在系统里**，你可以登录界面逐个翻看（项目编号见下）。

系统里会多出这些：

| 项目编号 | 对应算例 |
|---|---|
| VERIFY-01 ~ VERIFY-08 | 算例 01 ~ 08 |
| VERIFY-05b、VERIFY-06b | 算例 05、06 的孪生对照 |

**不想留了就清理掉：**

```bat
python 工具\数值核对\验证用例.py --clean
```

> ⚠️ **要生成软著材料（截图、说明书）之前，请务必先执行上面的清理。**
> 否则"项目与矿山档案""适宜性评价"这些列表页的截图里会带上这一堆
> 验证数据，看起来乱七八糟。

## 四、方式二：自己在界面上手动核对

想亲自走一遍流程、顺便熟悉系统，用这个方式。下面以**算例 01**为例。

### 第 1 步：建项目

1. 左侧菜单点 **项目与矿山档案**
2. 点 **新建项目** 按钮
3. 项目名称随便填（比如 `我的验证1`），编号随便填
4. 点 **保存**

### 第 2 步：建图斑

回到项目列表，找到刚建的项目，右侧点 **＋ 新建图斑**（图斑数为 0 时显示这个字样）。

| 字段 | 填什么 |
|---|---|
| 图斑名称 | 随便填，比如 `验证图斑1` |
| 图斑面积（公顷） | `10` ← **算例 03 要特别注意，见下方注意事项** |

其余字段可以留空，直接点 **保存**。

### 第 3 步：划分微地质单元

1. 左侧菜单点 **微地质单元**
2. 找到刚建的图斑，点 **划分与维护**
3. 页面下方 **添加微地质单元** 区域，按下表填，每填一个点一次 **添加**：

| 算例 | 类型 | 面积 |
|---|---|---|
| 01 | 碎石边坡 | 10 |
| 02 | 平台 | 10 |
| 03 | 岩质边坡 / 碎石边坡 / 平台 | 2 / 5 / 3（**必须按这个填**） |
| 04 | 碎石边坡 | 10 |
| 05 | 岩质边坡 | 10 |
| 06 | 平台 | 10 |
| 07 | 岩质边坡 | 10 |
| 08 | 碎石边坡 | 10 |

> 除了算例 03，其他算例都只有一个单元，面积填多少都行
> （只有一个单元时占比恒为 100%）。
> **算例 03 必须按 2 / 5 / 3 填**，否则占比就不是 20%/50%/30%，结果对不上。

添加完检查一下页面上方的 **占比合计** 是不是 `100.00%`。

### 第 4 步：限制性条件判定

1. 左侧菜单点 **限制性指标判定**
2. 找到图斑，点 **执行判定**
3. 五项（政策约束、区位约束、土壤污染、地质灾害、耕地属性）每项都选 **通过**
4. 点 **保存判定**

页面上会出现绿底提示"判定结论：通过，可进入定量评价"。

> **算例 08 反过来做**：把 **耕地属性** 那一项选 **不通过**，其他四项通过。

### 第 5 步：导入指标数据

1. 左侧菜单点 **指标数据采集**
2. 点 **批量导入（CSV / Excel）**
3. **目标矿山图斑**：选刚建的那个图斑
4. **数据文件**：点"选择文件"，进到 `验证数据` 文件夹，选对应的 CSV

| 算例 | 选哪个文件 |
|---|---|
| 01 | `用例01_理想上限_碎石边坡.csv` |
| 02 | `用例02_理论下限_平台.csv` |
| 03 | `用例03_面积加权_三单元混合.csv` |
| 04 | `用例04_污染取限值_碎石边坡.csv` |
| 05 | `用例05_岩质边坡忽略土壤指标.csv` |
| 06 | `用例06_平台忽略地形指标.csv` |
| 07 | `用例07_坡度分界_坡向赋值.csv` |
| 08 | `用例08_一票否决_耕地不通过.csv` |

5. 点 **开始导入**

导入结果里应该显示 **成功导入 1 个单元**（算例 03 是 3 个单元），
**问题行 0**。

> 如果显示"问题行"不为 0，通常是**单元类型对不上** ——
> 比如 CSV 里写的是"碎石边坡"，但你在第 3 步建的是"平台"。

### 第 6 步：执行评价

1. 左侧菜单点 **适宜性定量评价**
2. 找到图斑，看 **前置条件** 那一列 —— 应该显示绿色的 **已具备**
3. 点右侧的 **执行评价**
4. 进到评价页后，会看到一条流程步骤条（限制性条件判定 / 划分微地质单元 /
   录入指标数据 都是"已完成"）
5. 点 **开始评价**

### 第 7 步：对照结果

结果页会显示 **最终评价因子 F**、**适宜性等级**、**推荐措施**，
下面是各微地质单元的得分表。拿它和下面这张表对：

## 六、每个算例具体在验什么

### 算例 01 理想上限 → 应该满分

所有指标都填**刚好等于理想值**：土石比 0.8、土层厚度 20、pH 7、
有机质 30、8 种重金属全 0、植被覆盖度 75、Shannon 0.7、坡度 25、坡向 阴坡。

每个指标标准化后都是满分 1，所以单元得分和总分都应该是 **1.0000**。

**能查出的问题**：如果哪个指标的标准化工式写错了，这里就会低于 1。

### 算例 02 理论下限 → 应该零分

所有指标都填**最差值**，8 种重金属全部取限值。

**能查出的问题**：如果标准化没有下限保护（比如出现负数），
或者空值被当成 0 以外的什么值处理，这里就会偏离 0。

> 这里特意用**平台**：平台不设地形指标，所以不受"坡向最低只能到 0.2"
> 的影响，才能取到真正的 0 分。如果换成碎石边坡，最低只能到 0.0165。

### 算例 03 面积加权 → 检验加权公式

三个单元设定不同的好中差，专门看**面积占比加权**这一步
（论文式(9)：F = Σ 面积占比 × 单元得分）。

占比 20% / 50% / 30%，三个单元得分 0.3916 / 0.3925 / 0.5400：

```
F = 0.2×0.3916 + 0.5×0.3925 + 0.3×0.5400
  = 0.07832 + 0.19625 + 0.16200 = 0.43657 → 0.4366
```

**能查出的问题**：如果把占比当成平均权重（各 1/3）来算，
结果会变成 0.4414 而不是 0.4366。

### 算例 04 污染取限值 → 检验污染指标

除污染外全部取最优，8 种重金属（Cd、Hg、Pb、Cr、As、Ni、Cu、Zn）
全部**刚好等于限值**，此时每种重金属得分都是 0，污染指标 = 0。

**结果 0.9259 是正常的**，不是 bug：污染项权重 0.17、土壤一级权重 0.44，
所以重金属全部超标最多只让总分掉 0.17×0.44 ≈ **7.4%**。

> 换句话说，论文的口径里重金属污染**主要靠限制性条件判定把关**
> （"土壤污染"那一项不通过就直接不进入定量评价），而不是靠扣分。

### 算例 05 / 06 不适用指标不能算进去

这两个是**最值得看**的：

- 算例 05：往**岩质边坡**里填了完整的土壤数据（土石比、厚度、pH、
  有机质、重金属）。但岩质边坡按论文表 3 **不设土壤指标**，
  这些数据必须被无视，结果应该和不填时一模一样。
- 算例 06：往**平台**里填了坡度 90 和坡向 阳坡。但平台**不设地形指标**，
  同样必须被无视。

**怎么判断对错**：用自动方式跑（方式一），脚本会另建一个
"不填这些多余指标"的孪生算例，要求两者 F **完全相同**。
只要多余指标被算进去了，两者就会分叉。

### 算例 07 坡度分界与坡向

坡度填 **57.5°**（超过 25° 分界），坡向填 **阴阳坡**：

- 坡度：`(90 − 57.5) ÷ (90 − 25) = 32.5 ÷ 65 = 0.5`
- 坡向：阴阳坡 = 0.6

**能查出的问题**：如果 25° 分界写成别的数，或者坡向赋值写反
（阴坡 0.2、阳坡 1.0），这里立刻就会不对。

### 算例 08 一票否决

数据本身和算例 01 一样（理想上限），但**耕地属性判定不通过**。

按论文 4.1 节，这类矿山应**直接判定为"人工辅助或生态重建"，
不进入定量评价**。

**能查出的问题**：如果限制性条件形同虚设、照样算分，
就会算出 F = 1.0000「适宜」—— 这是最严重的逻辑错误。

## 七、CSV 文件的格式

CSV 文件用 **Excel 双击就能打开**，不会乱码。列的顺序是：

```
单元类型, 土石比, 土层厚度, pH, 有机质, Cd, Hg, Pb, Cr, As, Ni, Cu, Zn,
植被覆盖度, Shannon, 坡度, 坡向
```

- **留空表示"不适用"**。比如岩质边坡那行的土壤列全是空的。
- **坡向只能填** 阳坡 / 阴阳坡 / 阴坡 三者之一。
- 数值列填**纯数字**，不要带单位（填 `10` 而不是 `10cm`）。

这些 CSV 是由验证脚本自动生成的，和脚本里的期望值同源，
不会出现"数据改了、期望值没跟着改"的情况。

如果你想自己改数据试试，直接改 CSV 就行；但要重新跑一遍自动核对的话，
记得先用 `--emit-csv` 恢复原样：

```bat
python 工具\数值核对\验证用例.py --emit-csv
```

## 八、常见问题

**Q：结果和期望值对不上，是我操作错了吗？**

先检查这三处，90% 的情况是这里：

1. **微地质单元的类型建错了**（CSV 里是"碎石边坡"，你建成了"平台"）
2. **算例 03 的面积没按 2 / 5 / 3 填**
3. **限制性条件判定忘了做**，或者某项没选"通过"

这些都排除后还是对不上，那可能就是系统真有 bug，告我一声。

**Q：导入时提示"图斑内不存在单元类型 XXX"？**

说明微地质单元的**类型名**和第 5 步 CSV 里的对不上。
CSV 里的类型名必须是 `岩质边坡` / `碎石边坡` / `平台` 三者之一，
而且要在第 3 步先建好。

**Q：点"开始评价"按钮是灰的？**

说明前置条件没齐。鼠标移到评价页的"当前流程状态"表格看，
缺哪一步补哪一步。三步都要做完：
① 限制性条件判定通过 → ② 划分微地质单元 → ③ 录入指标数据。

**Q：跑完自动核对后，系统里多了一堆项目怎么办？**

那是正常的，算例故意保留下来方便你翻看。不想要了就运行：

```bat
python 工具\数值核对\验证用例.py --clean
```

**Q：我在"指标体系与权重"里改过权重，期望值还对得上吗？**

对不上了。这套期望值是按**论文表 3 的默认权重**算的。
如果你用层次分析法算过新权重并点了"保存并生效"，评价就会按新权重算。

想还原：进 **指标体系与权重** 页面，下方"各微地质单元当前生效权重"表格里，
改过的那一行会多出一个 **恢复默认** 按钮，点它即可。
如果表格里没有这个按钮，说明本来就在用论文表 3 的默认权重，无需还原。
