# 验证数据

用来检验**系统算得对不对**的算例数据。8 个算例的期望值全部按论文公式
**手工推算**得出，再与系统结果比对，而不是拿系统输出当标准。

## 从这里开始

👉 **[使用说明.md](使用说明.md)** —— 怎么跑、怎么在界面上核对、常见问题

## 一条命令自动核对

```bat
python 工具\数值核对\验证用例.py
```

建算例 → 跑评价 → 逐个比对期望值（含每个单元的得分与等级边界），
最后输出「系统计算正确 ✓」或列出不一致项。

```bat
python 工具\数值核对\验证用例.py --clean      :: 清理算例
python 工具\数值核对\验证用例.py --emit-csv   :: 重新生成下面的 CSV
```

> ⚠️ 生成软著材料（截图、说明书）前请先 `--clean`，
> 否则列表页截图会带上这些验证数据。

## 文件

| `用例01_理想上限_碎石边坡.csv` | 全部指标取最优，期望 F = 1.0000 |

| `用例03_面积加权_三单元混合.csv` | 三单元 2/5/3 ha，期望 F = 0.4366 |
| `用例04_污染取限值_碎石边坡.csv` | 8 种重金属全达限值，期望 F = 0.9259 |
| `用例05_岩质边坡忽略土壤指标.csv` | 多填土壤数据，期望 F = 0.4896 |
| `用例06_平台忽略地形指标.csv` | 多填坡度坡向，期望 F = 1.0000 |

由 `工具/数值核对/验证用例.py --emit-csv` 生成，与脚本里的期望值同源。

## 覆盖范围

- 理想上限、理论下限（标准化的两极）
- 面积加权合成（论文式(9)）
- 重金属污染指标（8 种等权）
- 不适用指标必须被忽略（岩质边坡无土壤、平台无地形），附孪生对照
- 坡度 25° 分界与坡向离散赋值
- 限制性条件一票否决
- 适宜性等级的三处边界（0.3 与 0.7 的归属）
