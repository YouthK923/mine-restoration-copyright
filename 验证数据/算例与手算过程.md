# 算例与手算过程

本文件记录 8 个验证算例的**手工推算过程**。期望值全部按论文式(8)、式(9)
与表 3、表 4 一步步算出来，再拿去和系统结果比对 —— 不从系统反算。

> 怎么跑、怎么在界面上核对，见 `使用说明.md`。

---

## 一、计算公式

### 指标标准化（论文 4.2.2 节，式(8)）

所有标准化结果限于 [0, 1]：

| 类型 | 公式 | 理想值 / 极值 |
|---|---|---|
| 越大越优 | `min(x / 理想值, 1)` | 土石比 0.8；土层厚度 20 cm；有机质 30 g/kg；植被覆盖度 75%；Shannon 多样性 0.7 |
| 越小越优 | `max(1 − x / 极值, 0)` | Cd 2；Hg 2；Pb 530；Cr 400；As 45；Ni 220；Cu 600；Zn 800（mg/kg） |
| pH（适中型） | [5, 9] 记 1；> 9 记 `max(10 − x, 0)`；< 5 记 `max(x − 4, 0)` | 理想区间 5~9 |
| 坡度 | ≤ 25° 记 1；> 25° 记 `max((90 − x) / 65, 0)` | 分界 25° |
| 坡向（离散） | 阳坡 0.2；阴阳坡 0.6；阴坡 1.0 | — |
| 污染 | 8 种重金属各自 `max(1 − 含量 / 限值, 0)`，再等权平均 | 缺测按 1（视为未受污染） |

### 得分合成（论文式(9)）

```
一级指标得分 = Σ(二级权重 × 二级标准化值) / Σ(二级权重)
               —— 不适用的指标不参与，权重也不计入分母

单元评价因子 F′ = Σ(一级权重 × 一级得分) / Σ(一级权重)

整矿评价因子 F = Σ(单元面积占比 × F′)
```

### 适宜性等级（论文表 4）

| F | 等级 | 推荐措施 |
|---|---|---|
| F < 0.3 | 不适宜 | 生态重建、人工辅助 |
| 0.3 ≤ F < 0.7 | 基本适宜 | 自然恢复为主，可辅以封闭场地和少量补种、补植、飞播等 |
| F ≥ 0.7 | 适宜 | 自然恢复 |

### 论文表 3 权重（系统默认）

| 单元类型 | 一级权重 | 二级权重 |
|---|---|---|
| **岩质边坡** | 植被 0.45、地形 0.55 | 植被：覆盖度 0.67、多样性 0.33<br>地形：坡度 0.64、坡向 0.36 |
| **碎石边坡** | 土壤 0.44、植被 0.31、地形 0.25 | 土壤：土石比 0.25、厚度 0.25、pH 0.17、有机质 0.17、污染 0.17<br>植被：覆盖度 0.64、多样性 0.36<br>地形：坡度 0.67、坡向 0.33 |
| **平台** | 土壤 0.54、植被 0.46 | 土壤：土石比 0.25、厚度 0.25、pH 0.17、有机质 0.17、污染 0.17<br>植被：覆盖度 0.61、多样性 0.39 |

> 注意：土壤五项二级权重之和是 **1.01**（论文表 3 原值
> 0.25+0.25+0.17+0.17+0.17），不是 1。系统按实际权重和归一化，
> 所以算例里出现的是 `1.01 / 1.01` 而不是 `1 / 1`。这是论文原值，
> 不做"修正"。

> 若在「指标体系与权重」里用 AHP 算过新权重并保存生效，评价会改用新权重，
> 下表的期望值不再适用。可在权重首页点「恢复默认」还原。

## 二、算例 01｜理想上限 → F = 1.0000

**输入**：碎石边坡 100%
土石比 0.8、土层厚度 20、pH 7、有机质 30、8 种重金属全 0、
植被覆盖度 75、Shannon 0.7、坡度 25、坡向 阴坡

```
土壤：
  土石比      0.8 / 0.8        = 1.0000
  土层厚度    20 / 20          = 1.0000
  pH          7 落在 [5,9]     = 1.0000
  有机质      30 / 30          = 1.0000
  污染        8 种均为 0 → 各自 1 − 0/限值 = 1 → 污染 = 1.0000
  土壤一级 = (0.25+0.25+0.17+0.17+0.17×1) / 1.01 = 1.01/1.01 = 1.0000

植被：
  植被覆盖度  75 / 75          = 1.0000
  多样性      0.7 / 0.7        = 1.0000
  植被一级 = (0.64+0.36) / (0.64+0.36)                     = 1.0000

地形：
  坡度        25 ≤ 25          = 1.0000
  坡向        阴坡             = 1.0000
  地形一级 = (0.67+0.33) / (0.67+0.33)                     = 1.0000

单元 F′ = 0.44×1 + 0.31×1 + 0.25×1 = 1.0000
F      = 1.0000 × 100% = 1.0000                           → 适宜
```

**能查出的问题**：任一指标的标准化工式写错，这里都会低于 1.0000。

## 三、算例 02｜理论下限 → F = 0.0000

**输入**：平台 100%（**平台无地形指标**）
土石比 0、土层厚度 0、pH 0、有机质 0、8 种重金属全部取限值、
植被覆盖度 0、Shannon 0

```
土壤：
  土石比      0 / 0.8          = 0
  土层厚度    0 / 20           = 0
  pH          0 < 5 → max(0−4, 0) = 0
  有机质      0 / 30           = 0
  污染        8 种均取限值 → 各自 1 − 1 = 0 → 污染 = 0
  土壤一级 = 0 / 1.01                                        = 0.0000

植被：
  植被覆盖度  0 / 75           = 0
  多样性      0 / 0.7          = 0
  植被一级 = 0 / 1.00                                        = 0.0000

单元 F′ = 0.54×0 + 0.46×0 = 0.0000
F      = 0.0000 × 100% = 0.0000                           → 不适宜
```

**为什么用平台**：平台不设地形指标，因此不受"坡向最低只能到 0.2"
的影响，才能取到真正的 0 分。若换成碎石边坡，地形那项最低也有
`0.33 × 0.2 = 0.066`，单元得分最低为 `0.25 × 0.066 = 0.0165`。

**能查出的问题**：标准化缺下限保护（出现负数）、或空值处理不当。

## 四、算例 03｜面积加权 → F = 0.4366

**输入**：三个单元，面积 2 / 5 / 3 公顷（合计 10），
故占比为 **20% / 50% / 30%**。

```
岩质边坡（占比 20%）：
  植被：覆盖度 0、Shannon 0                    → 0.0000
  地形：坡度 25 记 1；坡向 阳坡 记 0.2
        地形 = (0.64×1 + 0.36×0.2) / 1.00      = 0.7120
  F′ = (0.45×0 + 0.55×0.7120) / 1.00           = 0.3916

碎石边坡（占比 50%）：
  土壤：五项全 0（污染取限值）                  → 0.0000
  植被：覆盖度 75、Shannon 0.7
        植被 = (0.64×1 + 0.36×1) / 1.00        = 1.0000
  地形：坡度 90 记 0；坡向 阴坡 记 1.0
        地形 = (0.67×0 + 0.33×1) / 1.00        = 0.3300
  F′ = (0.44×0 + 0.31×1 + 0.25×0.33) / 1.00    = 0.3925

平台（占比 30%）：
  土壤：五项全取最优                            → 1.0000
  植被：覆盖度 0、Shannon 0                      → 0.0000
  F′ = (0.54×1 + 0.46×0) / 1.00                = 0.5400

F = 0.2×0.3916 + 0.5×0.3925 + 0.3×0.5400
  = 0.07832 + 0.19625 + 0.16200
  = 0.43657  →  0.4366                                    → 基本适宜
```

**能查出的问题**：若把面积占比当成等权（各 1/3）计算，
F 会是 0.4414 而不是 0.4366；若某类单元没有按类型取到对应权重，
差异更大。

## 五、算例 04｜污染取限值 → F = 0.9259

**输入**：碎石边坡 100%，除污染外全部取最优，
8 种重金属**全部刚好等于限值**。

```
污染：8 种均取限值 → 各自 1 − 1 = 0 → 污染 = 0.0000
（其余四项均取最优 = 1.0000）

土壤一级 = (0.25×1 + 0.25×1 + 0.17×1 + 0.17×1 + 0.17×0) / 1.01
         = 0.84 / 1.01 = 0.8316832

植被一级 = 1.0000
地形一级 = 1.0000

单元 F′ = 0.44×0.8316832 + 0.31×1 + 0.25×1 = 0.9259406
F      = 0.9259                                           → 适宜
```

**这个结果是正常的，不是 bug**：污染项权重 0.17、土壤一级权重 0.44，
重金属全部超标最多只让总分下降 `0.17 × 0.44 ≈ 7.4%`。

论文的口径里，重金属污染**主要靠限制性条件判定把关**——「土壤污染」
那一项判定不通过，就直接判定为"人工辅助或生态重建"，根本不进入定量评价
（见算例 08）。定量评价阶段的重金属扣分是第二道、较轻的一道。

**能查出的问题**：若污染指标漏算、或 8 种金属未等权处理，
这里会明显高于 0.9259。

## 六、算例 05｜岩质边坡忽略土壤指标 → F = 0.4896

**输入**：岩质边坡 100%，CSV 里**故意填了完整的土壤数据**
（土石比 0.8、土层厚度 20、pH 7、有机质 30、8 种重金属全 0）。

岩质边坡按论文表 3 **不设土壤指标**，因此这些值必须被完全忽略，
结果应与"完全不填土壤数据"时**完全相同**。

```
参与计算的只有植被与地形两项：
  植被：覆盖度 75 → 1；Shannon 0.7 → 1
        植被 = (0.67×1 + 0.33×1) / 1.00              = 1.0000
  地形：坡度 90 → (90−90)/65 = 0；坡向 阳坡 → 0.2
        地形 = (0.64×0 + 0.36×0.2) / 1.00            = 0.0720

F′ = (0.45×1 + 0.55×0.072) / 1.00
   = 0.45 + 0.0396 = 0.4896
F  = 0.4896                                            → 基本适宜
```

**怎么判断对错**：自动核对脚本会另建一个孪生算例「验证5b」，
**不填任何土壤数据**，要求两者 F 完全相同。只要土壤被算了进去，
两者就会分叉。

## 七、算例 06｜平台忽略地形指标 → F = 1.0000

**输入**：平台 100%，CSV 里**故意填了坡度 90 和坡向 阳坡**。

平台按论文表 3 **不设地形指标**，这些值必须被完全忽略。

```
  土壤：五项全取最优
        土壤 = (0.25+0.25+0.17+0.17+0.17×1) / 1.01 = 1.0000
  植被：覆盖度 75、Shannon 0.7
        植被 = (0.61×1 + 0.39×1) / 1.00             = 1.0000

F′ = (0.54×1 + 0.46×1) / 1.00 = 1.0000
F  = 1.0000                                            → 适宜
```

**怎么判断对错**：同样有孪生算例「验证6b」，不填坡度坡向，要求 F 相同。

## 八、算例 07｜坡度分界与坡向赋值 → F = 0.7448

**输入**：岩质边坡 100%，植被覆盖度 75、Shannon 0.7、
**坡度 57.5°**、**坡向 阴阳坡**

```
  植被：覆盖度 75 → 1；Shannon 0.7 → 1
        植被 = (0.67×1 + 0.33×1) / 1.00              = 1.0000
  地形：坡度 57.5 > 25 → (90 − 57.5) / (90 − 25)
                       = 32.5 / 65                   = 0.5000
        坡向 阴阳坡                                   = 0.6000
        地形 = (0.64×0.5 + 0.36×0.6) / 1.00
             = 0.32 + 0.216                           = 0.5360

F′ = (0.45×1 + 0.55×0.536) / 1.00
   = 0.45 + 0.2948 = 0.7448
F  = 0.7448                                            → 适宜（刚好越过 0.7）
```

**能查出的问题**：25° 分界值写错、或用别的折减方式（如按 25/x 折减，
那会得到 0.3945 而不是 0.5000）；坡向赋值写反（阴坡 0.2、阳坡 1.0）。

## 九、算例 08｜一票否决 → 不产生评价结果

**输入**：碎石边坡 100%，指标数据**与算例 01 完全相同**（理想上限），
但把限制性条件判定里的 **耕地属性** 设为 **不通过**。

按论文 4.1 节，此类矿山应**直接判定为"人工辅助或生态重建"，
不进入定量评价**。

```
期望：点「开始评价」时被拦下，页面提示
      「无法执行评价 —— 限制性条件判定未通过……」
      且不产生任何评价结果（数据库 evaluation_results 表不新增记录）
```

**能查出的问题**：如果限制性条件形同虚设、照样算分，
就会算出 F = 1.0000「适宜」—— 这是最严重的逻辑错误，
因为它会让一块耕地被判定为"适宜自然恢复"。

## 十、等级边界核对

论文表 4 的分界口径是 **F < 0.3 不适宜、0.3 ≤ F < 0.7 基本适宜、
F ≥ 0.7 适宜**，即**下界含、上界不含**：

| F | 等级 |
|---|---|
| 0.0000 | 不适宜 |
| 0.2999 | 不适宜 |
| **0.3000** | **基本适宜**（含下界） |
| 0.6999 | 基本适宜 |
| **0.7000** | **适宜**（含下界） |
| 1.0000 | 适宜 |

自动核对脚本会直接调等级判定函数把这 6 个点都验一遍。
如果边界写成"F ≤ 0.3 为不适宜"，0.3000 就会判错。
