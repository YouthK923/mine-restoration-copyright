# 系统制作步骤与分工

## 历史遗留废弃矿山自然恢复适宜性评价系统 V1.0

---

## 〇、开工必读

**1. 分工方式**：按**功能模块**划分，甲负责 4 个模块、乙负责 5 个模块，两人各自把自己的模块从数据到界面独立做完，尽量不互相等待。

**2. 环境已查过**：Python 3.12.7（Anaconda）已装，Flask、SQLAlchemy、NumPy、openpyxl、python-docx 都有。只缺 3 个库，一条命令：

```
pip install flask-login flask-wtf
```

**3. 有个坑要绕开**：环境里的 pandas 是坏的（用 NumPy 1.x 编译，和当前 NumPy 2.2.6 不兼容）。**本项目不使用 pandas**，Excel 读写改用 openpyxl。

**4. 独立的前提**：`models.py`（数据表）和 `templates/base.html`（页面框架）由**甲在第一天一次性写完定死**，之后两人只读不改。这是两人能独立开工的基础。

## 一、分工总览

| | **甲：核心计算线** | **乙：业务支撑线** |
|---|---|---|
| 模块 | M6 指标体系与 AHP 权重<br>M7 指标数据采集与管理<br>M8 适宜性定量评价引擎<br>M9 报告与结果输出 | M1 账号与权限管理<br>M2 项目与矿山档案<br>M3 政策与标准知识库<br>M4 限制性指标判定<br>M5 微地质单元管理 |
| 特点 | 算法强相关，权限→数据→评价→报告，一条完整链路 | 数据管理类，逻辑相似（列表 + 表单 + 增删改查），一个写熟后面都快 |
| 难度 | 高（算法是系统核心） | 中（结构重复，可复用套路） |
| 交接点 | 只在最后联调时对接一次 | 同上 |

**为什么这样切**：甲这条线是"算分"，乙这条线是"备料"。乙把矿山档案、微地质单元、限制性判定这些**基础数据**准备好，甲的引擎才能算。两人各自内部闭合，只在最后对接。

## 四、接口契约（两人都要照这个写）

这是两人能独立的**关键**。以下是模块之间传递的数据格式，**字段名和结构提前定死**，各自按此实现。

### 4.1 乙的 M5 面积占比 → 甲的 M8

```python
# 甲从数据库读，结构固定
[
  {"unit_type": "岩质边坡", "area": 0.776, "ratio": 0.1386},
  {"unit_type": "碎石边坡", "area": 3.525, "ratio": 0.6295},
  {"unit_type": "平台",     "area": 1.299, "ratio": 0.2319},
]
```

### 4.2 乙的 M7 指标数据 → 甲的 M8

```python
{
  "unit_type": "碎石边坡",
  "soil_ratio": 0.34,          # 土石比，None 表示不适用
  "thickness": 10,             # 土层厚度 cm
  "ph": 9.24,                  # pH
  "organic_matter": 4.89,      # 有机质 g/kg
  "heavy_metals": {            # 重金属 mg/kg
      "Hg": 0.05, "As": 5.17, "Ni": 12.60,
      "Cu": 11.70, "Cd": 0.04, "Pb": 6.50
      # 未检测的 Cr、Zn 用 None
  },
  "coverage": 87.92,           # 植被覆盖度 %
  "shannon": 0.60,             # Shannon-Wiener 多样性指数
  "slope": 28.75,              # 坡度 °，None 表示不适用
  "aspect": "阳坡",            # 坡向：阳坡 / 阴阳坡 / 阴坡，None 表示不适用
}
```

> **注意**：`None`（不适用）与 `0`（实测为 0）含义不同。论文案例中岩质边坡的土石比、厚度为"不适用"，平台无坡度坡向。计算时跳过 `None`，不当作 0 分。

### 4.3 乙的 M4 限制性判定 → 甲的 M8

```python
{"passed": True, "reasons": ["政策约束通过", "区位约束通过", "..."]}
# passed=False 时，M8 不执行计算，直接输出"人工辅助或生态重建"
```

### 4.4 甲的 M8 输出（给 M9 报告用）

}

## 八、需要提前定下来的三件事

| 事项 | 说明 | 已定方案 |
|---|---|---|
| **"不适用"与"实测为 0"怎么区分** | 岩质边坡土石比为 0 是"不适用"，不是"差"。若都当 0 算会拉低得分 | 数据库用可空字段，`None` 表示不适用，计算时跳过 |
| **系统装在哪台机器** | 决定环境怎么配 | 各自电脑本地跑；Windows + SQLite，不用装数据库 |
| **界面用不用 Bootstrap** | 决定页面怎么写 | 用 Bootstrap，界面规整且省时间 |
