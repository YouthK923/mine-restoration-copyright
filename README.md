## 案例数值验证程序

`案例数值验证.py` 用于核对论文第 5 节玉田县案例数值的内部一致性。仅依赖 Python 标准库：

```bash
python 案例数值验证.py
```

程序做三项核对：

1. **最终得分**：三个单元得分按面积占比加权，复算得 **0.74**，论文表 5 所载为 **0.76**，差 0.02。
2. **单元得分可复现性**：由表 5 原始数据按式(8) 标准化、与表 3 权重按式(9) 合成，无法复现
   岩质边坡 0.56 与碎石边坡 0.74 —— 碎石边坡所需地形分 0.811 超出可达上限 0.736。
3. **权重可还原性**：表 3 权重可写成某个完全一致判断矩阵的主特征向量，但专家原始判断矩阵不可唯一确定。

**差异定位**：土壤指标与植被指标的标准化均可复现；平台单元（不设地形指标）计算结果 0.842 与论文 0.85 仅差 0.008；
两处显著差异均集中在**地形指标（坡度、坡向）的标准化口径**。

> 程序所有输入数据逐字取自论文原表，未作修改；结论仅涉及数值一致性核对。
